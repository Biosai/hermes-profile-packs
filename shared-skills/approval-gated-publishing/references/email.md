# Email rules

Apply these to every campaign, automated flow and one-off mailing before asking for approval.

## The message
- A plain-text part beside the HTML part.
- A working unsubscribe link, tested from a test send.
- An honest sender: a From name and address the recipient would recognise, on a domain the brand controls.
- A footer line saying why the person receives the message.

## Consent
- No proof of consent, no mailing.
- A "subscribed" status set by an import file is not proof. Get the owner's statement that those people opted in before the import, and record it, dated, in the project brief.
- The owner's go on the campaign does not replace the consent statement: they are two separate approvals.
- State the consent basis and the audience size in the approval request.

## Testing
- Test sends go to the owner's own address.
- An automated flow is tested while it is switched off. Switching it live is a publishing action and needs its own approval.

## Scheduling
- Scheduling a send is a send that happens later: it needs the same approval.
- After scheduling, read the item back from the platform and compare its send time, with its time zone, with the approved one.
